# Настройка котировок

## Why

Дилеру нужен один предсказуемый процесс настройки котировок на уровне символа.

## Capabilities

- **CAP-1 — Symbol-first scope**
- **CAP-2 — Текущее состояние символа**
- **CAP-3 — Inline-редактирование одного символа**
- **CAP-4 — Отдельное массовое изменение**
- **CAP-5 — Current и calculated book**
- **CAP-6 — MaxSpread**
- **CAP-7 — Проверка перед применением**
- **CAP-8 — Безопасное применение и честный результат**
